## 🎮 Описание проекта

**NEON HOOK** - это аркадная игра с одним касанием (one-button game) в неоновом стиле. Игрок управляет персонажем, который цепляется за точки крюком, раскачивается и отпускает в нужный момент для полёта по касательной.

**Ключевые особенности:**
- Одна кнопка управления (нажал - зацепился, отпустил - полетел)
- Система комбо и наград за точность
- Процедурная генерация уровней
- Адаптивная сложность
- Неоновая визуальная стилистика с эффектами свечения (bloom)

**Платформы:**
- Мобильные устройства (Android, iOS) - основной фокус
- Десктоп (браузер)
- Яндекс.Игры (SDK интеграция)

## ✅ Реализованные механики

### 1. Физика и движение

- **Зацеп крюком:** герой цепляется за точки в радиусе `grabRadius = 3.5` юнита
- **Вращение:** угловая скорость от 3 до 5.5 рад/сек с ускорением
- **Полёт по касательной:** при отпускании герой летит с текущей скоростью
- **Приоритет точек:** выбор точки по маршруту (`idx * 100`), а не по расстоянию
- **Направление вращения:** определяется по стороне подлёта или угловому моменту
- **Анимация верёвки:** плавная интерполяция длины к целевой (`targetR`)

### 2. Система комбо

| Надпись | Условие | Награда |
|---------|---------|---------|
| **ПЕРФЕКТ** | Зацеп за следующую точку без пропуска | Комбо +1 |
| **ЦЕП!** (зелёный) | Зацеп в первые 0.2с после релиза | Комбо +1 |
| **ПУФ!** (голубой) | Отпускание в первые 0.2с после зацепа | Комбо +1 |
| **ДАЛЬНИЙ!** (розовый) | Пролёт ≥75% от максимальной высоты | +3◈ + комбо |
| **МЕГА-ПРЫЖОК!** (розовый) | Пролёт ≥100% от максимальной высоты | +5◈ + комбо |
| **Время вышло** (красный) | Не успел зацепиться за 1 секунду | Сброс комбо |

**Множители комбо:**
- 0-2 зацепа: ×1.0
- 3-5 зацепов: ×1.5
- 6-9 зацепов: ×2.0
- 10+ зацепов: ×3.0

### 3. Камера

- **Адаптивный lookahead:** камера смотрит вперёд по направлению движения
- **Динамический обзор:** сужается на старте (10 юнитов), расширяется на скорости (до 16 юнитов)
- **Резиновая лента:** лава ускоряется если герой далеко, замедляется если близко
- **Разморозка:** камера начинает следовать после первого зацепа
- **Плавность:** все изменения через lerp для избежания рывков

### 4. Опасности

- **Лава:** поднимается снизу, ускоряется со временем
- **Шипы:** разбросаны между точками, убивают при касании
- **Стены:** невидимые границы по бокам, смерть при выходе

### 5. Визуальные эффекты

- **Bloom:** свечение через offscreen canvas с размытием
- **Частицы:** при зацепе, смерти, сборе монет
- **Трейл:** след за героем (28 точек)
- **Тряска камеры:** при зацепе и смерти
- **Вспышки:** при идеальных действиях
- **Прогресс-бар:** над героем показывает прогресс дальнего прыжка

## 🔧 Технические улучшения

### Производительность

- **Оркестратор качества:** LOW (один канвас), MEDIUM (простой bloom), HIGH (два канваса)
- **Автозацеп:** раз в 3 кадра для экономии CPU
- **Очистка сущностей:** удаление точек/монет/шипов за пределами экрана
- **Быстрые проверки:** пропуск точек далеко по X/Y до вычисления расстояния

### UX

- **Вибрация:** при зацепе (с настройкой в меню, отключается для бота)
- **Восстановление звука:** после сворачивания приложения
- **Локализация:** русский и английский языки
- **Сохранение:** localStorage + Yandex Cloud (двойное сохранение)
- **Настройки:** громкость музыки/звуков, тряска, вспышки, вибрация, качество графики

### Интеграции

- **Yandex Games SDK:** лидерборды, облачные сохранения, реклама (interstitial/rewarded)
- **Аттракт-режим:** бот играет на фоне меню для привлечения внимания

## 🎯 Планы на будущее

### Приоритет 1: Обучение (Tutorial)

**Проблема:** новые игроки не понимают механику игры

**Что нужно:**
- Автоматический запуск обучения при первом запуске
- 3 зацепа с замедлением времени
- Надписи «НАЖМИ И ДЕРЖИ» / «ОТПУСКАЙ»
- Лава не двигается, шипы не убивают в обучении
- Кнопка «Обучение» в меню для перезапуска

**Цель:** улучшить D1 retention

---

### Приоритет 2: Улучшение камеры

**Проблема:** текущая камера вызывает укачивание

**Что нужно:**
- Уменьшить агрессивность адаптивного lookahead
- Увеличить плавность изменений (больше smoothness)
- Возможно: зафиксировать обзор, убрать динамическое расширение
- Тестировать на разных девайсах

**Цель:** комфортная игра без укачивания

---

### Приоритет 3: Адаптивная сложность

**Проблема:** игра может быть слишком лёгкой или сложной

**Что нужно:**
- Параметр `difficulty` в конфиге
- Уменьшение расстояния между точками с ростом высоты
- Увеличение скорости лавы
- Больше шипов на высоких уровнях
- Динамическая подстройка под игрока

**Цель:** удержание опытных игроков

---

### Приоритет 4: Монетизация

**Варианты:**
- **Щиты за рекламу:** 3 секунды неуязвимости после просмотра
- **Феникс:** второй шанс после смерти за rewarded video
- **Пак новичка:** скины + монеты за первый вход
- **Баннеры:** interstitial между играми (с троттлингом 60 сек)

**Цель:** доход без ухудшения UX

---

### Приоритет 5: Мелкие улучшения

- **Умное определение качества:** по `hardwareConcurrency` и `deviceMemory`
- **Фикс .gitignore:** проверить что все build-артефакты игнорируются
- **Удаление отладочных логов:** `console.log` для релиза
- **Оптимизация генерации:** кэширование вычислений

## 🐛 Известные проблемы

### Текущие (не критичные)

1. **Укачивание от камеры** - нужно настроить плавность
2. **BOM символ в canvas.js** - косметика,不影响功能
3. **Опечатка в логе** - `vy` выводится как `vx` в `doRelease()`

### Потенциальные риски

1. **Производительность на слабых девайсах** - нужно тестировать на старых телефонах
2. **Баланс сложности** - может быть слишком легко/сложно
3. **Retention новых игроков** - без обучения может быть низким

## 📊 Метрики для отслеживания

- **D1 Retention:** % игроков вернувшихся на следующий день
- **Session Length:** средняя длина сессии
- **Average Height:** средняя высота за игру
- **Ad Completion Rate:** % просмотров рекламы до конца
- **Crash Rate:** % крашей (должен быть <1%)
